# Part B - Pick ONE option

Part B is worth up to 15 marks. Choose **one** option and work only in its folder.

- **Option 1 - watchOS App (5 marks):** a lightweight Apple Watch companion to your Part A app. Choose this if you cannot commit the extra time for Option 2. Folder: `Option1-watchOS/`
- **Option 2 - visionOS App (15 marks):** a more advanced spatial computing prototype for Apple Vision Pro. Aim for full marks here, but expect significantly more work. Folder: `Option2-visionOS/`

**Do not submit both.** Delete the folder for the option you did not choose, or leave it empty with its README intact. Record your choice in `STUDENT_DETAILS.md`.
